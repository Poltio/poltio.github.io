Multi-Widget — Three Triggers

Three widgets match this page, so the SDK serves poltio_multi.js and mounts each one under its own instance.

Panel rules: a pill at bottom-left and a product card (floating-product-child-number 2) on this exact URL; a box at bottom-right on https://poltio.github.io/test-cases/multi/*. Each with its own content.

Expected behavior

  • The script request returns the multi bundle: three containers, ids suffixed -2 and -3 for the second and third.
  • Each trigger opens its own panel. While one is open the others are hidden (multi-open style is present) and page scroll is locked; closing it brings them back.
  • At phone width the open panel fills the screen and nothing paints over it.
  • Each widget reports its own cta-view with its own widget_id.
