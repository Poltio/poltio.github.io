Multi-Widget — SPA Navigation

Client-side route changes between a multi page and a single-widget page. Each change tears every widget down and loads the SDK again for the new URL.

Panel rules: a pill at bottom-left on this exact URL; the box at bottom-right on https://poltio.github.io/test-cases/multi/*. Nothing extra on other.html, so only the box matches there.

Expected behavior

  • On spa.html: two widget divs, ids ending -2 present.
  • After "Go to other.html": one widget div, the box only, and no ids ending -2 left behind.
  • After "Back to spa.html": both widgets again, each still opens its own panel.
  • Open a panel, then change route: scroll unlocks and no multi-open style is left.
  • "Next page" only bumps ?page=N, which the SDK ignores: no reload, so sdk loads and widget mounts stay the same, and an open panel stays open. A route change bumps both.
