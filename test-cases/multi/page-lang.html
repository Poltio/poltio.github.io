Multi-Widget — Page Language

The server does not know the page language, so it serves every match; each widget then checks its own language list in the browser. A widget limited to another language skips itself without affecting the others.

Panel rules: a pill at bottom-left limited to trigger-page-langs tr and a card at top-right, both on this exact URL; the box at bottom-right on https://poltio.github.io/test-cases/multi/*. This page is <html lang="en">.

Expected behavior

  • The script carries three widgets, but only the card and the box mount: three widget divs, two containers.
  • Two cta-view requests, none for the Turkish pill.
