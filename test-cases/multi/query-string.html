Multi-Widget — Query Strings and Two Product Cards

Every saved query URL a page satisfies is a match, not only the best one, so widgets saved on different query strings share a page. Two product cards in one grid each land on the tile they are configured for.

Panel rules: a pill at bottom-left on ?utm_source=x (474); a box at top-right on ?campaign=y (475); product cards on tile 2 (476) and tile 4 (477) on this page without a query; the box at bottom-right on https://poltio.github.io/test-cases/multi/* (449).

Expected behavior

  • ?utm_source=x&campaign=y: all five widgets (474 and 475 in either order, then 477, 476, 449). Before this change only one of the two query widgets was served.
  • ?utm_source=x: the pill, both product cards and the box (474, 477, 476, 449); ?campaign=y: the top-right box instead of the pill.
  • No query: both product cards and the box (477, 476, 449).
  • The cards sit before Puffer Jacket (tile 2) and before Biker Jacket (tile 4), never one tile early.
  • Opening any widget closes whichever other one is open; only one panel at a time.
