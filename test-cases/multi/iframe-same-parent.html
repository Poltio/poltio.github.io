Multi-Widget — Two Embeds, One Container

Two iframe widgets are aimed at the same container. Mounting both would let one overwrite the other and count two impressions for one quiz, so only one is served.

Panel rules: two iframe triggers with floating-parent-id poltio-inline, both on this exact URL (widgets sharing a URL rank newest id first); the box at bottom-right on https://poltio.github.io/test-cases/multi/*.

Expected behavior

  • The bordered area holds exactly one quiz, from the newer widget.
  • The box still floats bottom-right: two widgets in the multi bundle, the older embed dropped on position.
