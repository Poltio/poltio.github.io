Multi-Widget — Same Content Twice

Two widgets on this page show the same quiz in different corners. Sharing a content is not a conflict: both are served, and each iframe's messages reach the iframe that sent them.

Panel rules: a pill at bottom-left on this exact URL with the same content as the box; the box at bottom-right on https://poltio.github.io/test-cases/multi/*.

Expected behavior

  • Both render from poltio_multi.js: the pill (bottom-left) as the first instance, the box (bottom-right) with -2 ids.
  • Opening either one loads the quiz in its own panel, sized to its own content; opening one never resizes or retitles the other's iframe.
  • The SDK request log drops nothing.
