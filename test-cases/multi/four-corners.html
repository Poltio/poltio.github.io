Multi-Widget — Four Corners

One widget in every corner. On desktop all four fit; on a phone two bottom teasers would overlap, so only the more specific bottom widget is served there.

Panel rules: a pill at top-left, a card at top-right and a pill at bottom-left on this exact URL; the box at bottom-right on https://poltio.github.io/test-cases/multi/*.

Expected behavior

  • Desktop: four widget divs, one per corner.
  • Phone (DevTools device mode with a phone user agent): three widget divs; the box is dropped because the bottom-left pill holds the bottom edge.
  • Opening any widget hides the other three until it closes.
