Product Card Tag

A sub-category row like arcelik.com.tr/buzdolabi: a ul that scrolls sideways with flex-wrap: nowrap, where the page sizes only its li tiles. The product card is created as an li via data-poltio-floating-product-tag, so it picks up the same rules. Configured on the element, so no panel rule is needed.

Expected behavior

  • One product card (li#poltio-product-card) appears as the first tile of the row below.
  • It is as wide and as tall as the other tiles, on desktop and on a phone, and the row still scrolls sideways on narrow screens.
  • Clicking it opens this page's widget panel; the floating card in the corner opens the same panel.
  • Remove the tag attribute (or set it to div) and the card collapses to 0px wide on a phone: the bug this setting fixes.
