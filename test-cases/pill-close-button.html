Pill Close Button

This page tests the pill trigger close button (data-poltio-floating-pill-show-close-button). A small X badge floats just above the top right of the pill.

Expected behavior

  • Clicking the X removes the pill immediately and keeps it hidden for the remember duration (data-poltio-floating-pill-close-remember-duration, set to 1 hour on this page; default is 48 hours).
  • After closing, reloading the page should not show the pill until the duration expires. To reset, remove the poltio-content-913eb3f7a1d5-closed key from localStorage.
  • Hovering the X keeps the pill expanded, same as hovering the pill.
  • Clicking the pill opens the widget; the X disappears while the widget is open and comes back when it is closed.

Any query parameter is applied to the trigger div as an attribute, e.g. ?data-poltio-floating-position=center-left.
