Box Close Button

This page tests the box trigger close button (data-poltio-floating-box-show-close-button). Configured on the element, so no panel rule is needed.

Expected behavior

  • On an expanded box the X only folds it back. On a folded box the X hides it and keeps it hidden for the remember duration (data-poltio-floating-box-close-remember-duration, set to 1 hour on this page; default is 48 hours).
  • Hiding writes poltio-content-b1a9044e-983b-4afc-afa3-5ccde8979198-closed to localStorage, with no -2 suffix. Reloading must not show the box until it expires; remove the key to reset.
  • Clicking the box opens the widget panel and locks page scroll; its close button collapses it and unlocks scroll.
