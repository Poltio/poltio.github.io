Double Load — Iframe, Late Parent

An iframe trigger whose parent #poltio-inline appears 1.5s after load, after both copies have run. Its retry used to be cancelled by the second copy replacing window.poltio.

Panel rules: an iframe trigger (floating-parent-id poltio-inline) on this exact URL.

Expected behavior

Open DevTools, tick Disable cache on the Network tab, and reload five or more times: the two scripts arrive in a different order each time.

  • The dashed box appears after 1.5s and the widget fills it at the 2s retry.
  • One inline iframe, one page-load hit.
