Double Load — Chatbot

Troy's setup: the snippet in the head, and a bare poltio.js tag hardcoded in the body. Whichever loaded second used to replace window.poltio, and the chat froze at 0 or 80px.

Panel rules: a chatbot on this exact URL.

Expected behavior

Open DevTools, tick Disable cache on the Network tab, and reload five or more times: the two scripts arrive in a different order each time.

  • The intro renders at its full height on every reload, never 0 or 80px.
  • Answering the first question grows the box to its cap; the transcript scrolls after that.
  • One container, one page-load hit.
